# 📊 1️⃣ Bar Plot

🔎 What is a Bar Plot?

A Bar Plot is used to represent **categorical data** with rectangular bars.

The height of each bar represents the value associated with a specific category.

# When to Use a Bar Plot?

- Comparing different categories
- Visualizing frequency counts
- Showing differences between groups
- Displaying discrete data

# Example Use Cases

- Student marks comparison by subject
- Product sales comparison
- Employee count by department
- Survey results analysis

# Key Insight

Bar plots make category comparison simple and visually intuitive, helping in quick decision-making.

# 📈 2️⃣ Histogram

# What is a Histogram?

A Histogram is used to represent the **distribution of numerical (continuous) data**.

It divides data into intervals called bins and shows the frequency of values in each bin.

# When to Use a Histogram?

- Understanding data distribution
- Checking skewness
- Identifying outliers
- Analyzing frequency patterns

#📌 Example Use Cases

- Exam score distribution
- Salary distribution analysis
- Age group analysis
- Product price range distribution

# 📈 Key Insight

Histograms help in understanding how data is spread and whether it follows a normal distribution.
